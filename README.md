### Hi, I'm Leander

I build [Brincr](https://brincr.com), a multi-tenant ERP for wholesale and e-commerce, from Nootdorp (NL).

**What I work on**

- Moving a large CodeIgniter codebase to Laravel, one module at a time, towards hexagonal + CQRS
- Letting AI agents do real engineering work: Claude Code workflows, MCP servers, characterisation tests before refactors
- Azure Container Apps and Terraform for everything that has to keep running at 3am

**What I've learned the hard way**

- Write the guard before the clever code. An agent will happily run `migrate:fresh` on the wrong database.
- Tests that pin today's behaviour beat tests that describe the behaviour you wish you had.
- Most "flaky" tests are a shared database in disguise.

**Stack:** PHP · Laravel · MySQL · Redis · TypeScript · Playwright · Terraform · Azure
